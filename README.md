# Serein — premium stays landing page

A responsive, dependency-free landing page for Serein, a fictional collection of considered stays. Built with semantic HTML, CSS, and a small JavaScript enhancement for mobile navigation.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the repository root to GitHub Pages on every push to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected.

Photography is loaded from Unsplash and typefaces from Google Fonts; those assets require an internet connection. The contact link is a mailto placeholder and should be replaced with the intended booking address before launch.
